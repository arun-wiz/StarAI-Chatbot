# Remediation Priority Guide

| Priority | Criteria | Timeline |
|----------|----------|----------|
| **P0** | Active exploit confirmed / CISA KEV listed / active compromise detected | Do now |
| **P1** | Toxic combination with external exposure / validated exploitable vuln in deployed asset | This sprint |
| **P2** | High severity, no confirmed exploitation, not externally exposed | Next sprint |
| **P3** | Medium / informational, no immediate risk | Backlog |
